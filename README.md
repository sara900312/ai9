# NEOMART AI Assistant (87)

أريد بناء واجهة NEOMART AI داخل مشروع NEOMART الحالي.

الهدف:

إنشاء واجهة Chat AI حديثة وجميلة تظهر في منتصف الصفحة عند الضغط على زر "AI Chat"، وتكون متناسقة بالكامل مع تصميم NEOMART الحالي، مع قدرة الـ AI على البحث في منتجات NEOMART وإظهار المنتجات المناسبة داخل المحادثة.

==================================================

1. هوية وتصميم الواجهة

==================================================

استخدم الصور المرفقة في هذه المهمة كمرجع بصري لتصميم الموقع الحالي.

أريد الحفاظ على هوية NEOMART الحالية:

- اللون الوردي الأساسي

- الأبيض

- التصميم النظيف

- المساحات البيضاء

- الخط العربي الواضح

- RTL

- التصميم المتجاوب

- أسلوب المتجر الحالي

لا تعيد تصميم الموقع بالكامل.

أضف فقط واجهة NEOMART AI بشكل احترافي ومتناسق مع التصميم الحالي.

عند الضغط على زر Chat AI الموجود في الموقع:

- افتح واجهة Chat في منتصف الشاشة.

- يمكن أن تكون Modal / Dialog كبيرة وأنيقة.

- الخلفية خلفها تكون معتمة بشكل خفيف.

- الواجهة تكون في المنتصف.

- على سطح المكتب تكون بعرض مناسب تقريبًا 700-900px.

- على الهاتف تكون Full-screen أو شبه Full-screen.

- RTL.

- Animation ناعم عند الفتح والإغلاق.

==================================================

2. واجهة NEOMART AI

==================================================

صمم Chat UI احترافي شبيه بتطبيقات AI الحديثة، ولكن بهوية NEOMART.

العناصر:

Header:

- شعار NEOMART AI

- أيقونة AI بسيطة

- زر إغلاق X

- عنوان مثل:

  "NEOMART AI"

- وصف صغير:

  "مساعدك الذكي لاكتشاف المنتجات المناسبة"

منطقة المحادثة:

- رسائل المستخدم على جهة.

- رسائل AI على الجهة الأخرى.

- تصميم فقاعات نظيف.

- Loading indicator أثناء انتظار الرد.

- دعم النص العربي RTL.

- دعم النص الإنجليزي عند الحاجة.

Input:

- مربع كتابة واضح.

- Placeholder:

  "اسألني عن أي منتج..."

- زر إرسال.

- دعم Enter للإرسال.

- Shift + Enter لسطر جديد.

- تعطيل زر الإرسال أثناء الطلب عند الحاجة.

- إظهار حالة Loading.

==================================================

3. AI BACKEND

==================================================

جميع رسائل الـ AI يجب أن تذهب إلى Supabase Edge Function التالية:

https://emobathinfpylwjdcfbo.supabase.co/functions/v1/neo-chat

لا تجعل Frontend يتصل مباشرة بأي AI provider.

التدفق يجب أن يكون:

User

 ↓

NEOMART AI Chat

 ↓

Supabase Edge Function

 ↓

neo-chat

 ↓

AI

 ↓

NEOMART AI Chat

استخدم:

VITE_SUPABASE_URL

VITE_SUPABASE_ANON_KEY

من Environment Variables.

لا تضع أي Secret أو API Key خاص بمزود AI داخل Frontend.

لا hardcode لأي API key.

استخدم متغيرات البيئة بشكل صحيح ومتوافق مع Vite وCloudflare production build.

==================================================

4. قاعدة بيانات المنتجات

==================================================

قاعدة بيانات المنتجات موجودة في Supabase التالية:

https://ykyzviqwscrjjkucorlp.supabase.co/rest/v1/

استخدم الـ public/anon key الموجود في Environment Variables للوصول إلى البيانات.

لا تضع المفتاح الفعلي داخل source code.

المطلوب أن يستطيع النظام قراءة بيانات المنتجات المتاحة من قاعدة البيانات، مثل:

- اسم المنتج

- الوصف

- السعر

- الصورة

- الفئة

- العلامة التجارية

- التوفر

- أي بيانات إضافية موجودة في جدول المنتجات

قبل كتابة الاستعلامات، افحص المشروع الحالي وحدد:

- اسم جدول المنتجات

- أسماء الأعمدة

- أنواع البيانات

- طريقة تخزين الصور

- الحقول المطلوبة للعرض

لا تفترض أسماء الجداول أو الأعمدة.

إذا كانت هناك طريقة موجودة حاليًا في المشروع لجلب المنتجات، أعد استخدامها بدل إنشاء نظام مكرر.

==================================================

5. AI PRODUCT SEARCH

==================================================

أريد أن يستطيع المستخدم كتابة طلب طبيعي مثل:

"أريد كريم مناسب للبشرة الجافة"

أو:

"أريد منتج سعره أقل من 20 ألف"

أو:

"شنو أفضل شامبو عندكم؟"

أو:

"أريد منتج للعناية بالشعر"

ويقوم AI بفهم الطلب وإظهار المنتجات المناسبة من قاعدة بيانات NEOMART.

المهم:

الـ AI لا يخترع منتجات.

لا يخترع:

- أسماء منتجات

- أسعار

- صور

- توفر

- روابط

أي منتج يظهر للمستخدم يجب أن يكون موجودًا فعليًا في قاعدة بيانات المنتجات.

==================================================

6. PRODUCT CARDS داخل Chat

==================================================

عندما يعثر AI على منتجات مناسبة، لا تعرضها كنص فقط.

أنشئ Product Cards داخل المحادثة.

كل Product Card يحتوي على:

- صورة المنتج

- اسم المنتج

- السعر

- وصف مختصر

- الفئة إن كانت متوفرة

- حالة التوفر إن كانت متوفرة

- زر:

"شراء المنتج"

يمكن أيضًا إضافة:

"عرض المنتج"

لكن لا تضف وظائف شراء حقيقية داخل الـ AI Chat.

8. زر شراء المنتج

==================================================

عند ظهور منتج داخل نتائج AI:

زر:

"شراء المنتج"

يجب أن ينقل المستخدم إلى الموقع الأساسي:

https://neomart.space/beauty/

لكن الأفضل إذا كان للمنتج رابط/slug/ID موجود فعليًا في قاعدة البيانات ويقود إلى صفحة المنتج، استخدم الرابط الحقيقي للمنتج بدل إنشاء رابط وهمي.

إذا لم توجد صفحة منتج منفصلة أو رابط منتج حقيقي:

استخدم:

https://neomart.space/beauty/

ولا تخترع URL للمنتج.

المهم أن زر الشراء لا ينفذ عملية دفع داخل Chat.

هو مجرد انتقال إلى موقع NEOMART.

10. AI SUGGESTIONS

==================================================

عند فتح Chat لأول مرة، اعرض اقتراحات جاهزة للمستخدم، مثل:

"ابحث لي عن منتج للعناية بالشعر"

"ما أفضل المنتجات للبشرة الجافة؟"

"أريد منتج بسعر مناسب"

"ساعدني أختار منتج"

عند الضغط على الاقتراح:

يتم وضع السؤال في Chat وإرساله إلى AI.

==================================================

11. CONVERSATION

==================================================

حافظ على سياق المحادثة أثناء فتح Chat.

مثلاً:

User:

أريد شامبو

AI:

هذه بعض الخيارات...

User:

أريد أرخص واحد

يجب أن يفهم AI أن "أرخص واحد" تشير إلى النتائج السابقة.

أرسل conversation history إلى neo-chat بالطريقة التي يتطلبها الـ Edge Function الحالية.

لا تفترض body format إذا كان المشروع يحتوي بالفعل على implementation للـ neo-chat.

افحص الـ Edge Function أو الكود الحالي أولًا.

==================================================

12. ERROR HANDLING

==================================================

إذا حدث خطأ:

- لا تجعل الشاشة سوداء.

- لا تجعل التطبيق ينهار.

- اعرض رسالة مفهومة للمستخدم.

مثال:

"عذرًا، حدث خطأ أثناء الاتصال بالمساعد الذكي. حاول مرة أخرى."

مع زر:

"إعادة المحاولة"

ولا تعرض:

- API keys

- Supabase keys

- stack traces

- معلومات سرية

للمستخدم.

13. SECURITY

==================================================

- وضع AI provider API key داخل Frontend.

- وضع service_role key في Frontend.

استخدم فقط الـ public/anon keys المناسبة للـ frontend.

==================================================

VITE_SUPABASE_ANON_KEY

VITE_SUPABASE_ANON_KEY
